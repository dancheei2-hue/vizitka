# Сайт-визитка — Данил Аверин, риелтор в Ижевске («Самолёт плюс»)

Одностраничный сайт-визитка в формате «ссылка в один клик»: HTML + CSS, без сборки и зависимостей. Открывается прямо из файла или разворачивается на GitHub Pages за пару минут.

## Структура

```
├── index.html      # вся разметка страницы
├── style.css       # стили (синяя палитра, в стиле референса «Самолёт плюс»)
└── assets/
    └── danil.jpg   # фото на главной
```

## Как развернуть на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `averin-site`).
2. Загрузите в него все файлы из этой папки (можно перетащить через веб-интерфейс GitHub, или через git — см. ниже).
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main** и папку **/ (root)** → **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу вида:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

## Через git из терминала

```bash
git init
git add .
git commit -m "Сайт-визитка Данила Аверина"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
git push -u origin main
```

Затем включите GitHub Pages, как описано в шаге 3–4 выше.

## Что можно донастроить

- **Ссылка на MAX**: MAX не поддерживает ссылки вида `max.ru/u/+7...` по номеру телефона — приложение выдаёт персональную ссылку только через «Профиль → Поделиться профилем». Сейчас кнопка «MAX» копирует номер телефона в буфер обмена (с подсказкой вставить его в MAX). Если сгенерируете свою персональную ссылку в приложении — пришлите, и её можно подставить как обычную ссылку вместо копирования номера (кнопка с `id="maxBtn1"` в `index.html`).
- **Сервис «Подбор новостройки»**: в текущей компактной версии отдельной кнопки для него нет (услуга упомянута в строке иконок на фото — «Подбор и консультации»). Когда сервис будет готов как отдельный инструмент со своей ссылкой, добавьте вторую карточку в блок `.links` по аналогии с «Продай сам» (`<a class="link link-tool">…</a>`), либо третью мини-кнопку в `.mini-row`.
- **Фото**: сейчас использовано ваше фото на фоне новостройки. Чтобы заменить — положите новый файл в `assets/` и поправьте `src` у `.hero-photo` в `index.html`; кадрирование (`object-position` в `style.css`) может понадобиться подстроить под новое фото.
- **Логотип «Самолёт плюс»**: сделан текстом и CSS (без файла-картинки) — слово «самолет» + синяя плашка «плюс» + подпись «Агентство недвижимости» (`.hero-logo` в `index.html`, стили `.logo-*` в `style.css`). Если у вас есть официальный файл логотипа компании, замените этот блок на `<img>`.
