# Визитка Данила Аверина, версия Taste Skill

Пересобранная версия текущей визитки на основе `dancheei2-hue/vizitka`.

Что изменено:
- асимметричная композиция вместо обычной карточки;
- крупная типографика и более выраженная иерархия;
- один основной акцентный цвет;
- premium-подход к карточкам и отступам;
- адаптивная desktop/mobile версия;
- мягкие scroll-reveal анимации;
- интерактивные hover-состояния;
- Phosphor Icons вместо эмодзи;
- сохранены текущие контакты, ссылки и фотографии;
- разделена визуальная система: hero → услуги → подход → «Продай сам» → контакты.

Сайт остается статическим и совместим с GitHub Pages.

Файлы `assets/` не дублируются в этой сборке: используются существующие изображения текущего репозитория.
